Detailed Description

Copyright (C) 2016 Patrick Mours. All rights reserved. License: https://github.com/crosire/blink#license Microsoft C/C++ MSF 7.00 (MSF = multi-stream file / compound file)

Raw file is subdivided into pages of fixed size. Those pages are grouped into content streams of variable size. The stream assignments to corresponding pages are defined in the root directory (and stream zero).
